# DBMS Practicals README

## Project Title

Database Management System (DBMS) Practicals using SQL and MongoDB

---

## Description

This project contains DBMS practical programs implemented using SQL, PL/SQL, and MongoDB.
The practicals demonstrate important database concepts such as table creation, constraints, joins, transactions, procedures, triggers, and NoSQL operations.

---

* MongoDB
* SQL
* PL/SQL
